# Reporting security issues

Email **app-support@droessmj.com** for vulnerabilities, privacy concerns, or anything that should not appear in a public GitHub issue. Include the affected app/version, reproduction steps using synthetic data, and the likely impact. Do not include credentials, real message bodies, verification codes, phone numbers, habit backups, or device diagnostic archives.

For ordinary questions, bugs, and feature ideas, use this repository’s **Issues** tab. Use made-up examples and check screenshots for private information before posting. GitHub issues in a public repository are visible to everyone.

These apps are built primarily for personal use and shared with others. Reports are reviewed as time allows; no response deadline or support service level is promised.

The apps use local device storage. Public bundle identifiers, App Group identifiers, and Apple team IDs are not authentication credentials. Signing private keys, provisioning profiles, installed app bundles, device logs, and personal app data must stay outside the public repository.
